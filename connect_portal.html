V2 API

1. Create Connected Account

POST /api/connect/accounts

Creates a connected account where the platform is responsible for pricing and fee collection (fees_collector: 'application').

Maps our platform user object to the new Stripe Account ID.

Platform Level

2. Create Product

POST /api/connect/products

Creates a product on the platform Stripe account. The mapping to the seller's connected account is stored in metadata and database.
